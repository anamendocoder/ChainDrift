## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/ChainDrift.git`
2. `cd ChainDrift`
3. Install in editable mode: `pip install -e .`

## Configuration

ChainDrift is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
